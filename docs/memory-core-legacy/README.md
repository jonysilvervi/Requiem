# Memory Core — legacy concept documents (v0.1)

These are the original Memory Core documents, written before the current
`memory-core/` archive existed. They describe the initial concept: Constitution,
MVP definition, early architecture, protocols and schemas, and the roadmap.

**They are superseded.** The current, approved Memory Core documentation is in
`memory-core/context/`:

| Legacy file (here) | Current equivalent |
|---|---|
| `FOUNDATION/REQUIEM_MEMORY_CORE_CONSTITUTION.md` (v0.1) | `memory-core/context/REQUIEM_FOUNDATION_DECISIONS.md` (v0.4, APPROVED) |
| `FOUNDATION/REQUIEM_MEMORY_CORE_MVP.md` (v0.1) | `memory-core/context/REQUIEM_MEMORY_CORE_MODEL.md`, `memory-core/context/REQUIEM_INSTANCE_MODEL.md` |
| `ARCHITECTURE/REQUIEM_MEMORY_CORE_ARCHITECTURE.md` (v0.1) | `memory-core/context/REQUIEM_MEMORY_ARCHITECTURE.md` |
| `PROTOCOLS/*` (v0.1) | `memory-core/protocols/REQUIEM_DEVELOPMENT_PROTOCOL.md` and the models in `memory-core/context/` |
| `SCHEMAS/*` (v0.1) | `memory-core/context/REQUIEM_ARCHITECTURE_MAP_FORMAT.md`, `memory-core/database/` (actual schema in use) |
| `FUTURE/REQUIEM_MEMORY_CORE_ROADMAP.md` (v0.1) | No current equivalent — the roadmap has not been reissued since the CP-006 checkpoint. Treat future planning as an open item. |

Kept for history only. Do not cite these as current architecture — if a claim needs
to be current, it must come from `memory-core/context/`, checked against
`memory-core/context/REQUIEM_DOCUMENT_REGISTRY.md`.
